AMBA SISILA WEB APP - V1 PROTOTYPE

Open index.html in a browser.

Included:
- Sinhala / English selector
- Dashboard
- POS / sales
- Cash / card selection
- Browser print for receipt workflow
- Products
- Basic stock tracking
- Expenses
- Reports
- Responsive mobile UI

Important: this prototype stores data in browser localStorage. It is NOT yet the production cloud version. The next build should add secure owner/employee login, cloud database, ingredient recipes/stock deduction, permissions, receipt formatting, backups and password reset.
